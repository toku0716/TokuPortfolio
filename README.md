## 🌌 Overview

ZEN大学 知能情報社会学部 2年生・Tokuの公式ポートフォリオサイトです。  
漆黒の深宇宙に濃く鮮烈な純白の星々が静かに流れる Three.js 空間演出と、エディトリアルなダークグラスデザインを採用しています。

---

## 🛠 Tech Stack

- **3D Graphics / Engine**: [Three.js](https://threejs.org/) (WebGL / Deep Space Starfield)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (CDN) & Custom Modern CSS
- **Typography**: [Inter](https://fonts.google.com/specimen/Inter)
- **Development**: AI対話駆動開発（AI Pair Programming）
