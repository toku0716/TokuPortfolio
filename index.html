Portfolio / 制作実績

推しサポ (Oshiss / Oshiss-Web)

Webアプリケーション / 2026年 / React 19, TypeScript, IndexedDB, WebRTC, PWA

予定管理・グッズ整理・ToDo管理を統合した推し活総合支援Webアプリです。「個人の大切な趣味データを外部サーバーに預けたくない」というプライバシー課題を解決するため、外部送信ゼロの完全端末内保存（IndexedDB）を採用しました。

  • 完全ローカル完結ストレージ: 個人データをサーバーに保存せず、オフラインでも全機能が動作。
  • WebRTCによるP2P直接同期: 中継サーバーにデータを預けず、6桁コード認証による端末間（PC⇔スマホ）直接暗号化データ引き継ぎを実装。
  • PWA対応: インストール不要で軽快に動作し、快適な利用体験を提供。
